# XYZ

>  **化学体系结构的 XYZ 文件** — 由 [MolStar](https://molstar.szbl.ac.cn/viewer/) 可直接读取的轻量级分子坐标格式

---

## 概述

**XYZ** 是一种非常常用的记录化学体系结构的文件格式，其定义极其简单，广受欢迎。

- **文件类型**：纯文本（可用任意文本编辑器打开）
- **主要用途**：存储分子/材料的原子坐标
- **坐标单位**：**埃（Å）**
- **兼容性**：可直接被 MolStar、VMD、PyMOL、Avogadro 等主流分子可视化工具读取

---

##  单帧 XYZ 文件格式

### 格式规范

| 行号 | 内容 | 说明 |
|:---:|------|------|
| 第 1 行 | 整数 `N` | 原子总数 |
| 第 2 行 | 字符串 | 标题/注释行（内容随意） |
| 第 3 ~ N+2 行 | `元素名  X  Y  Z` | 每个原子的元素符号及三维直角坐标 |

### 示例：水分子

以下是一个典型的 `.xyz` 文件，记录了一个 **水分子（H₂O）** 的结构：

```txt
3
Generated by Multiwfn
O      -0.00000000     -0.00000000      0.11930801
H       0.00000000      0.75895306     -0.47723204
H      -0.00000000     -0.75895306     -0.47723204
```

### 字段说明

```txt
┌─────────────────────────────────────────────────────────┐
│  3                       ← 原子数                        │
│  Generated by Multiwfn    ← 标题行（任意文本）            │
│  O   -0.00000000  -0.00000000   0.11930801  ← O 原子坐标 │
│  H    0.00000000   0.75895306  -0.47723204  ← H 原子坐标 │
│  H   -0.00000000  -0.75895306  -0.47723204  ← H 原子坐标 │
└─────────────────────────────────────────────────────────┘
```

| 字段 | 含义 | 示例值 | 单位 |
|------|------|--------|------|
| 元素名 | 原子元素符号（大写开头） | `O`、`H` | — |
| X | X 轴坐标 | `-0.00000000` | Å |
| Y | Y 轴坐标 | `-0.00000000` | Å |
| Z | Z 轴坐标 | `0.11930801` | Å |

##  XYZ 轨迹文件（多帧）

XYZ 格式天然支持 **多帧连续写入**，形成分子动力学轨迹文件。每一帧都遵循相同的「原子数 → 标题 → 坐标块」结构，依次排列即可。

### 格式规范

```
[帧 1: 原子数 + 标题 + N 行坐标]
[帧 2: 原子数 + 标题 + N 行坐标]
[帧 3: 原子数 + 标题 + N 行坐标]
...
```

> ⚠️ **注意**：轨迹文件中每一帧的**原子数必须相同**，原子顺序也建议保持一致，否则可视化时会出现"原子跳变"的伪影。

### 示例：5 帧水分子轨迹

以下文件可解析为 **5 帧** 轨迹数据，坐标单位仍为 **埃（Å）**：

````txt
3
Frame 1 - Generated by Multiwfn
O      -0.00000000     -0.00000000      0.11930801
H       0.00000000      0.75895306     -0.47723204
H      -0.00000000     -0.75895306     -0.47723204
3
Frame 2 - Generated by Multiwfn
O      -0.00000000     -0.00000000      0.11930801
H       0.00000000      0.75895306     -0.47723204
H      -0.00000000     -0.75895306     -0.47723204
3
Frame 3 - Generated by Multiwfn
O      -0.00000000     -0.00000000      0.11930801
H       0.00000000      0.75895306     -0.47723204
H      -0.00000000     -0.75895306     -0.47723204
3
Frame 4 - Generated by Multiwfn
O      -0.00000000     -0.00000000      0.11930801
H       0.00000000      0.75895306     -0.47723204
H      -0.00000000     -0.75895306     -0.47723204
3
Frame 5 - Generated by Multiwfn
O      -0.00000000     -0.00000000      0.11930801
H       0.00000000      0.75895306     -0.47723204
H      -0.00000000     -0.75895306     -0.47723204
````

### 轨迹文件结构示意

```
┌─────────────────────────────────────────┐
│  Frame 1  ╠══ N + 标题 + 坐标块        │
├─────────────────────────────────────────┤
│  Frame 2  ╠══ N + 标题 + 坐标块        │
├─────────────────────────────────────────┤
│  Frame 3  ╠══ N + 标题 + 坐标块        │
├─────────────────────────────────────────┤
│  Frame 4  ╠══ N + 标题 + 坐标块        │
├─────────────────────────────────────────┤
│  Frame 5  ╠══ N + 标题 + 坐标块        │
└─────────────────────────────────────────┘
         ↑ 每帧结构完全相同，仅坐标不同
```

## 快速参考速查表

| 属性 | 说明 |
|------|------|
| 文件扩展名 | `.xyz` |
| 文件类型 | 纯文本 |
| 坐标单位 | **埃（Å）** |
| 坐标体系 | 三维直角坐标系 |
| 原子数限制 | 无（受内存限制） |
| 多帧支持 | ✅ 天然支持（轨迹） |
| 电荷/力常数 | ❌ 不包含（需扩展格式） |
| 键连信息 | ❌ 不包含（通常自动推断） |
| 速度信息 | ❌ 不包含 |
| MolStar 兼容 | ✅ 直接读取 |
