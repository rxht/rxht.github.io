# RXH

> **RXH** 是一种简洁的分子结构文件格式，支持 **原子坐标 + 键连信息** 的完整描述，可被 [MolStar](https://molstar.szbl.ac.cn/viewer/) 直接读取并渲染。本文结合 `1TQN` 实例，逐行拆解其文件结构、字段含义与读取顺序。

---

## 格式概览

| 属性 | 说明 |
|------|------|
| **文件扩展名** | `.rxh` |
| **文件类型** | 纯文本（ASCII） |
| **核心内容** | 标题行、原子数量、原子坐标、键连数量、键连关系 |
| **坐标单位** | 埃（Å） |
| **适用场景** | 分子可视化、结构传递、MolStar 快速加载 |
| **直接读取工具** | [MolStar](https://molstar.szbl.ac.cn/viewer/) |

---

## 文件结构

RXH 文件由 **两大区块** 组成，自上而下依次为：

```
┌─────────────────────────────────────────┐
│  第 1 行     │ 标题（Title）            │
│  第 2 行     │ 原子数量（AN）           │
├──────────────┼──────────────────────────┤
│  第 3 ~ AN+2 │ 原子坐标区块（每行一个）  │
│  行          │ element  x  y  z         │
├──────────────┼──────────────────────────┤
│  第 AN+3 行  │ 键连数量（BN）           │
│  行          │                          │
├──────────────┼──────────────────────────┤
│  后续 BN 行  │ 键连关系区块（每行一条）  │
│              │ atom1  atom2  order      │
└─────────────────────────────────────────┘
```

## 单帧结构示例（1TQN）

以下以 PDB ID `1TQN` 的简化 RXH 文件为例，展示完整结构：

```txt
1TQN
3999
    N    -30.07000    8.17800    -13.89100
    C    -29.61800    8.22600    -15.31500
    C    -28.09800    8.41600    -15.43700
    O    -27.57400    9.54400    -15.45900
    C    -30.34900    9.35000    -16.06500
    ... (省略后续原子)
3908
    1    2    1
    2    5    1
    2    3    1
    ... (省略后续键连)
```

## 字段逐行说明

### 区块一：文件头

| 行号 | 字段 | 说明 | 示例值 |
|------|------|------|--------|
| 1 | **标题** | 任意字符串，通常写分子名称或 PDB ID | `1TQN` |
| 2 | **原子数量（AN）** | 正整数，表示后续原子坐标的行数 | `3999` |

### 区块二：原子坐标（共 AN 行）

每行描述一个原子，格式为 **4 列**，列间以空白分隔：

```
元素符号    X坐标    Y坐标    Z坐标
```

| 列 | 字段名 | 类型 | 单位 | 说明 |
|----|--------|------|------|------|
| 1 | `element` | 字符串 | — | 元素符号（如 `C`、`N`、`O`、`H`） |
| 2 | `x` | 浮点数 | Å（埃） | X 轴笛卡尔坐标 |
| 3 | `y` | 浮点数 | Å（埃） | Y 轴笛卡尔坐标 |
| 4 | `z` | 浮点数 | Å（埃） | Z 轴笛卡尔坐标 |

> ⚠️ **注意**：原子坐标采用 **笛卡尔坐标系**，单位为 **埃（Å）**，与 PDB 格式一致。

### 区块三：键连信息

| 行号 | 字段 | 说明 | 示例值 |
|------|------|------|--------|
| AN + 3 | **键连数量（BN）** | 正整数，表示后续键连关系的行数 | `3908` |

### 区块四：键连关系（共 BN 行）

每行描述一条化学键，格式为 **3 列**：

```
原子1索引    原子2索引    键级
```

| 列 | 字段名 | 类型 | 说明 |
|----|--------|------|------|
| 1 | `atom1_index` | 整数 | 第一个原子的 **1-based 索引**（对应原子坐标区块的行号） |
| 2 | `atom2_index` | 整数 | 第二个原子的 **1-based 索引** |
| 3 | `order` | 整数 | 键级：`1` = 单键，`2` = 双键，`3` = 三键 |

> ⚠️ **索引从 1 开始**，即第 1 个原子对应坐标区块的第 1 行（文件第 3 行）。
